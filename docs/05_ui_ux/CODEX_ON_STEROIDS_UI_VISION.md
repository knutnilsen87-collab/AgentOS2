# AgentOS UI direction – Codex on steroids

## Core product direction
AgentOS should feel as immediately usable as Codex, but stronger on:
- review
- verification
- approvals
- evidence
- risk clarity
- project continuity

## Mental model
Do not build a dashboard-first app.
Do not build a generic chatbot app.

Build a **thread-first workspace** with an operational control layer.

## Primary layout
- Left: projects, threads, routines, memories
- Center: active thread with artifact-rich blocks inline
- Right: approvals, evidence, affected files, verification
- Bottom: persistent chat/command dock
- Footer: runtime dock

## Product rule
The user should always be able to:
- start fast like Codex
- understand the current state faster than Codex
- review more safely than Codex
- verify more explicitly than Codex

## Guided vs advanced
Guided should reduce what is shown.
Advanced should increase density and detail without changing the structural frame.
